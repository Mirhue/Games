# Kingpin v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add icons, stacking crew weapons with perks, leveled skills (plus a Street Life branch), and perk businesses to Kingpin, with balance verified by the simulation.

**Architecture:** Same layers as v1. A new `effect(state, key)` in `js/engine.js` sums perks from skills, weapons and businesses, and caps live in `js/data.js`. Icons are static SVGs in `assets/icons/`, drawn as CSS masks.

**Tech Stack:** Vanilla ES modules; Node 22 for tests and the sim; Playwright (in the scratchpad) for browser checks.

**Spec:** `docs/superpowers/specs/2026-10-10-kingpin-v2-design.md`

## Global Constraints
- All v1 global constraints still hold: no deps or build, pure engine, integer cash, everything tunable in `data.js`.
- `SAVE_VERSION = 2`, and v1 saves migrate.
- Perk caps: nerveRegen ≤ 1.0, heatDecay ≤ 2.0, heatReduction ≤ 0.75, nerveMax ≤ 150.

## Review Focus
1. **Old v1 saves with `true` flags** must load with correct levels and counts. A test covers v1→v2.
2. **Stacking perks past the caps:** buy 100 Tommy guns and nerve regen must still be 2× at most. A test covers each cap.
3. **Buying the next level of a maxed skill** must be refused (`reason: 'max'`). Tested.
4. **Unlocking:** node 2 opens once node 1 is at level 1. Upgrading node 1 further doesn't relock or break anything. Tested.
5. **Missing icon files** must not break the page: the CSS mask simply shows nothing. A test checks that every `icon` in `data.js` has a file in `assets/icons/`.
