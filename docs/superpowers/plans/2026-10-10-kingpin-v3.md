# Kingpin v3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rework vault economics, add the Old Pro nerve-saving skill, and add a metals market with mean-reverting prices and news.

**Architecture:** Same layers. The market rules live in a new pure module `js/market.js`: rng and now are passed in, and it uses the engine's state shape. Re-exports from `engine.js` keep a single API surface for the UI and sim. All numbers live in `data.js`.

**Tech Stack:** Vanilla ES modules; Node 22 for tests and the sim; Playwright for browser checks.

**Spec:** `docs/superpowers/specs/2026-10-10-kingpin-v3-design.md`

## Global Constraints
- All v1/v2 constraints hold: no deps, pure engine, integer cash, tunables in `data.js`.
- Metals are never lost to raids, seizure or fights.
- Market expectation: random trading loses about the spread.

## Review Focus
1. **A save without `market`:** it must initialise and not crash. Test: migrate `{version: 2}` → prices at fair value.
2. **Huge offline gap:** the market must not loop for weeks of steps. Test: a 30-day gap finishes in under 100 ms and re-draws.
3. **Selling more bars than owned, or buying with too little cash:** refused, nothing changes. Tested.
4. **Price stays positive and finite for extreme news and long runs.** Tested with a seeded 30-day run.
5. **Net worth after a crash drops, and the Godfather check uses it.** Tested.
